PRS GAMING WEBSITE — GITHUB IMPORT

FILES
- index.html: the complete website (HTML + built-in CSS + tiny year script).

UPLOAD TO GITHUB
1. Create or open your GitHub repository.
2. Choose Add file > Upload files.
3. Upload index.html from this folder.
4. Click Commit changes.
5. To publish it, open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.

EDITING
- Open index.html in any text editor or GitHub's web editor.
- Search for EDIT: to find the main customization notes.
- Change words directly between the HTML tags.
- Change a link by replacing the URL inside href="...".
- Replace the sample email YOUR-EMAIL@example.com with your contact email.
- Replace the # links in the footer with your social profile URLs.
- Duplicate a <article class="player-card"> block to add a player.
- Change the sample player names, roles, games, and news text.

The site is responsive and uses a black, white, and electric-blue PRS theme.
