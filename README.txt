GITHUB UPLOAD
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Click Add file > Upload files.
4. Upload index.html.
5. Click Commit changes.
6. To publish: Settings > Pages > Deploy from a branch > main > /(root) > Save.

EDITING
Open index.html in GitHub's editor or any text editor.
Search for "EDIT THIS" to find the main edit points.
Change a link by replacing the URL inside href="...".
Change names and wording directly in the HTML.
Duplicate a player <article class="player"> block to add roster members.
Replace YOUR-EMAIL@example.com and the # social links with your own.
